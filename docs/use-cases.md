# BizKit India — Market Validation Notes

## High-confidence Indian use cases
1. Freelancer GST billing
- Fast GST-compliant invoice generation
- IGST/CGST/SGST breakup for intra/interstate work
- WhatsApp-first distribution

2. Small shop cash-profit check
- Daily cash sales entry
- Quick profit view by category/product
- Low-friction dashboard for non-accountants

3. Advance tax / presumptive estimator
- Quarterly revenue + expenses input
- Liability estimate under old/new regime
- Plain-language note: "consult a CA"

4. Quarterly GSTR tally helper
- CSV summaries of sales vs input credit
- Reducer for anxiety at filing time

5. Service vs product margin comparator
- Profitability per line item/service
- Mix-business view for café/reseller use cases

## Competitor gaps
- Tally/Busy: desktop-first, pricey, steep learning curve
- Zoho Books/RazorpayX: overbuilt for solo freelancers, thin free tier
- MyBillBook/Vyapar: weak tax estimation and profit analytics
- QuickBooks India: accountant-centric, not shop-owner-friendly
- Excel/Sheets: no automation, high manual error

## Differentiators to prioritize
- WhatsApp-first invoice sharing
- Indian numbering formatting option (lakhs/crores)
- Hindi + English localization
- Preset GST rate shortcuts
- Year-end ITR kit export: PDF/CSV handoff for CA
- Offline-first with optional cloud backup
- UPI/receipts workflow with basic OCR-friendly fields
